# OpenCode 1.19.0 接口与安装验证

日期：2026-11-25。初版运行代码为 `2ed6c4a`，平台 OpenCode 1.19.0，Node.js 24.15.0，
Python 3.12。[完整模块实验](opencode-v1-full-flow-2026-11-25.zh.md)记录八阶段 EDA 流程。
本报告保留接口、安装和恢复检查。

## 原生接口

以 `npm pack` 产物安装到独立 OpenCode 服务器，使用隔离的 XDG 配置和脚本化 localhost
provider。测试代码为 `tests/runtime/opencode.py`。

| 场景 | 实际观察 |
|---|---|
| 正常执行 | 发现 12 个技能；独立子会话加载当前 lint-cdc 正文；完成后父会话收到结果 |
| 命令拒绝 | `bash: deny` 下测试命令未执行 |
| 审批拒绝 | 命令未执行，宿主停止当前轮次 |
| 取消 | 子会话记录 MessageAbortedError；宿主确认退出后显式恢复父会话成功 |
| 关闭后台能力 | schema 不暴露 background，强行调用报错，没有启动执行器 |

v1.19.0 的取消操作不会发送正常完成通知，使用说明据此要求确认退出后恢复父会话。
适配保留宿主权限和命令文本。五项原生检查通过；初版共享测试为 1164 passed、31 skipped。

## 真实模型与生命周期

真实 DeepSeek `deepseek-flash` 会话完成了以下检查：

- 规格交付、独立后台审查、修复和 kernel 收集；当时的任务仅包含 specification。
- 两个后台检查任务重叠约 42 秒，父会话收齐结果；12 个技能路径、kernel 及阶段 CLI
  的帮助入口均可解析。
- 在 bash 被禁止的会话中报告查询受阻，没有绕过权限执行 kernel。
- 更新安装来源、重启服务器后续接原会话，使用新安装目录中的 kernel 查询已有 proof。
- 独立 `opencode run --format json` 加载技能并完成真实 kernel 状态查询。

临时 checkout 的自动发现、更新内容后重启、禁用、重新启用，以及两个不同包来源的
安装/切换和移除均已检查：启用时 12 个技能，移除后为 0。更新验证使用不同来源，
没有把重启等同于刷新同名 Git ref 的缓存。

初次实验还发现 README 遗留 v2 接口，以及测试辅助代码错误比较 URL 编码路径。
二者已修改仓库文件；安装目录内的相关单元检查随后为 12 passed。

## 环境探测

`env-precheck` 实际运行 DC、PT/PX、VCS/UVM、URG、FSDB、SpyGlass lint/CDC，生成了
对应产物。探测发现 EDA 容器只挂载 `/home/mhc`，宿主 `/tmp` 不可见。最初 DC scratch
写到默认 `/home/mhc/.vp-env-precheck`，偏离指定范围，后续工作纠正并记录原始路径；
其余 smoke 通过容器内暂存执行。后来的完整模块实验直接在挂载路径内运行全部阶段。

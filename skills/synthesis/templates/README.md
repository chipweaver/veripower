# synthesis stage project template

This directory holds the project template for the `veripower:synthesis` stage. Path: `${CLAUDE_SKILL_DIR}/templates/`.
For the stage SOP and artifact definitions, see `${CLAUDE_SKILL_DIR}/SKILL.md`; for a bootstrap quick reference, see `${CLAUDE_SKILL_DIR}/references/makefile-bootstrap.md`.

## Deployment

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/synthesis/__main__.py bootstrap \
     --module <module-dir-name> --workdir <abs-path> [--top <top-module>]
```

`--workdir` is the synthesis stage's per-run workspace (typically
`asic/<module>/Design/synthesis/runs/<N>/`, supplied by the caller). What the
script substitutes and generates — placeholders, `scripts/rtl_load.tcl` (incl.
`+incdir+` → `search_path`), `scripts/config.tcl`, SDC source-of-truth, abort-on-
already-deployed, `--top` inference — is documented once in
[`../references/makefile-bootstrap.md`](../references/makefile-bootstrap.md).

## Files to check after deployment

| File | What to confirm / fill in |
|------|----------------|
| `scripts/config.tcl` | Whether `LIB_DB` points to a valid standard-cell library file (replace the `FILL_IN_LIB_DB_PATH` placeholder). |
| `constraints.sdc` | Clock periods, IO delays, clock uncertainty, timing exceptions; placeholder values must be flagged with a `# notes:` comment for later replacement. |
| `scripts/rtl_load.tcl` | Whether the bootstrap-generated content covers all RTL files. |

## Running

```bash
cd <workdir>           # i.e. asic/<module>/Design/synthesis/runs/<N>/

make synthesis    # Runs dc_shell synthesis; log → run.log, netlist → out/<TOP>_syn.v
make clean        # Cleans intermediate artifacts and report files
```

`make synthesis` requires `LIB_DB` to be set first; see the two ways to set it in
[`../references/makefile-bootstrap.md`](../references/makefile-bootstrap.md) §LIB_DB setup.

## File descriptions

| File | Description |
|------|------|
| `env.sh` | Environment variables: `TOP`, `LIB_DB` (the `MY_TOP` placeholder is substituted at deployment). |
| `Makefile` | Build entry point; manages the `synthesis` / `clean` targets. |
| `constraints.sdc` | Timing constraints (when no source of truth: contains `MY_TOP` substituted to the actual name; when a source of truth exists: used as-is). |
| `scripts/dc_run.tcl` | Design Compiler main synthesis script (the `MY_RTL_DIR` placeholder is substituted at deployment). |
| `scripts/rtl_load.tcl` | RTL `analyze` list, regenerated by bootstrap from filelist.txt (the template content is a placeholder only). |
| `scripts/config.tcl` | Generated by bootstrap; injects `TOP` / `LIB_DB` for dc_shell (which does not inherit shell environment variables). |

## Outputs

| Path | Contents |
|------|------|
| `out/<TOP>_syn.v` | Synthesized gate-level netlist (Verilog). |
| `out/<TOP>_syn.sdc` | Post-synthesis SDC. |
| `out/<TOP>_syn.sdf` | Post-synthesis SDF v3.0 timing annotation. |
| `reports/qor.rpt` | Quality of Results summary. |
| `reports/area.rpt` | Area hierarchy report. |
| `reports/timing_setup.rpt` | Setup timing report (max_paths 20). |
| `reports/timing_hold.rpt` | Hold timing report (max_paths 20). |
| `reports/power.rpt` | Synthesis-stage power estimate (the power-analysis stage judges power_mw; this stage only scans it once). |
| `reports/check_design.rpt` | `check_design` output. |
| `run.log` | DC run log. |
| `ppa-actual.json` | Structured PPA record (`verdict` + `ppa_actual[]` + `violations[]`) from `synthesis finalize`. |

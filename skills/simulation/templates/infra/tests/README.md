# tests directory

- `testlist.json` is generated by the sim bootstrap verb (render-scaffold) at bootstrap time, from `scaffold-specification.json.tests[]`.
- This file is the machine-readable testcase list for the `simulation` stage; it is consumed by `scripts/run_vcs_regression.sh` and `scripts/write_summary.py`.
- When coverage iteration (Rule B) needs new testcases, **append** entries (do not change the semantics of existing entries; semantic-level changes belong to the plan domain and simulation does not exceed its authority).
- A testcase's "should be so" semantics come from `Verification/simulation-plan/scaffold-specification.json.testpoints[]` and `verification-plan.md §3`; simulation consumes them read-only.
